วางระบบ Network ให้พร้อม
สำหรับกล้อง IP Camera

เข้าใจการออกแบบเครือข่าย ตั้งแต่สาย LAN, PoE Switch, Bandwidth, VLAN และ NVR เพื่อให้ระบบกล้องวงจรปิดทำงานได้เสถียรและพร้อมขยายในอนาคต

ADVANCE NETWORK CCTV　·　คู่มือระบบเครือข่ายสำหรับงาน CCTV

การติดตั้งกล้อง IP Camera ไม่ได้จบแค่การเลือกกล้องและเครื่องบันทึกภาพ แต่ต้องออกแบบเครือข่ายให้รองรับการรับส่งข้อมูลและการจ่ายไฟอย่างเหมาะสมด้วย หากระบบ Network ไม่พร้อม อาจเกิดภาพกระตุก กล้องหลุด หรือบันทึกภาพไม่ต่อเนื่องได้

1. ทำความเข้าใจโครงสร้างระบบ IP Camera

ระบบพื้นฐานประกอบด้วยกล้อง IP Camera, PoE Switch, NVR และ Router / Gateway โดยกล้องส่งข้อมูลภาพผ่านสาย LAN ไปยัง Switch จากนั้นส่งต่อไปยัง NVR เพื่อบันทึกภาพ ส่วน Router / Gateway ทำหน้าที่จัดการเครือข่ายและเชื่อมต่ออินเทอร์เน็ตตามการออกแบบ

ตัวอย่างโครงสร้างระบบ IP Camera

🌐
Internetการเชื่อมต่อภายนอก
🛡️
Router / Gatewayจัดการ IP และเส้นทางเครือข่าย
🔀
PoE Switchรับส่งข้อมูลและจ่ายไฟให้กล้อง
📷
IP Cameraจับภาพและส่งข้อมูล

เชื่อมต่อ NVR เข้ากับ Switch หรือเครือข่ายกล้องตามแบบที่ออกแบบ เพื่อรับภาพและบันทึกข้อมูล

ในระบบจริง NVR อาจเชื่อมต่อเข้ากับ PoE Switch โดยตรง หรือใช้พอร์ตเครือข่ายแยกตามความสามารถของอุปกรณ์ ควรตรวจสอบคู่มือและโครงสร้าง IP ก่อนตั้งค่า

2. เลือกสาย LAN ให้เหมาะกับกล้อง IP Camera

สาย LAN ใช้ทั้งรับส่งข้อมูลและจ่ายไฟ PoE จึงควรเลือกสายทองแดงแท้ที่ได้มาตรฐาน เหมาะกับสภาพแวดล้อมและระยะติดตั้ง หลีกเลี่ยงสาย CCA สำหรับงาน PoE ที่ต้องการความน่าเชื่อถือ

Cat5e · 100 MHz

รองรับ Gigabit Ethernet ในระยะตามมาตรฐาน เหมาะกับระบบ IP Camera ทั่วไป

Cat6 · 250 MHz

มีคุณสมบัติด้านสัญญาณรบกวนที่ดีขึ้นเมื่อเข้าระบบอย่างถูกต้อง เหมาะกับงานใหม่และการเผื่อขยายระบบ

ระยะ Channel ของ Ethernet แบบ Twisted Pair โดยทั่วไปไม่ควรเกิน 100 เมตร แบ่งเป็น Permanent Link สูงสุด 90 เมตร และ Patch Cord รวมไม่เกิน 10 เมตร หากต้องเดินไกลกว่านี้ให้พิจารณา Fiber Optic หรือจุดกระจายสัญญาณเพิ่มเติม

3. เลือก PoE Switch ให้เพียงพอกับจำนวนกล้อง

PoE Switch ส่งข้อมูลและจ่ายไฟผ่านสาย LAN เส้นเดียวกัน ช่วยลดการเดินสายไฟแยก แต่ต้องตรวจสอบทั้งจำนวนพอร์ต มาตรฐาน PoE และกำลังไฟรวม (PoE Budget)

  • จำนวน Port: ต้องพอกับกล้องและอุปกรณ์ที่ต้องเชื่อมต่อ พร้อมเผื่อการขยาย
  • PoE Budget: กำลังไฟรวมที่ Switch จ่ายได้ ต้องมากกว่าความต้องการรวมของกล้อง
  • มาตรฐาน PoE: ตรวจสอบว่าอุปกรณ์รองรับ IEEE 802.3af, 802.3at หรือ 802.3bt ตรงกัน
  • Uplink: ตรวจสอบความเร็วพอร์ตเชื่อมต่อไปยัง NVR หรือ Core Switch
ตัวอย่างคำนวณ PoE Budget:
กล้อง 8 ตัว ใช้กำลังไฟสูงสุดตัวละ 12W จะต้องใช้กำลังไฟรวม 8 × 12 = 96W ควรเลือก Switch ที่มี PoE Budget สูงกว่า 96W และเผื่อกำลังไฟสำหรับช่วงที่กล้องเปิดไฟส่องสว่างหรือใช้ฟังก์ชันเสริม

4. คำนวณ Bandwidth ให้เพียงพอกับจำนวนกล้อง

กล้องแต่ละตัวส่งข้อมูลภาพเข้าสู่ระบบตลอดเวลา ปริมาณข้อมูลขึ้นอยู่กับความละเอียด Frame Rate, Codec, Bitrate และลักษณะภาพที่กล้องบันทึก

ตัวอย่าง: กล้อง 4MP จำนวน 8 ตัว ตั้ง Bitrate เฉลี่ยตัวละ 4Mbps
8 × 4Mbps = 32Mbps
ระบบต้องรองรับข้อมูลภาพขาเข้าจากกล้องประมาณ 32Mbps และควรเผื่อ Bandwidth สำหรับการดูภาพสด เล่นย้อนหลัง และการใช้งานอื่น ๆ

ควรตรวจสอบ Switching Capacity, Forwarding Performance และความเร็ว Uplink ของ Switch รวมถึง Incoming Bandwidth ของ NVR ด้วย เพราะพอร์ตกล้องที่เป็น Gigabit ไม่ได้แปลว่าทุกส่วนของระบบจะรองรับได้เพียงพอโดยอัตโนมัติ

5. ใช้ VLAN แยกเครือข่ายเพื่อความเป็นระเบียบและปลอดภัย

ในสำนักงานหรือโรงงานที่ใช้งานเครือข่ายร่วมกันหลายประเภท การแยก VLAN ช่วยแบ่งกลุ่มอุปกรณ์และกำหนดสิทธิ์การเข้าถึงได้ชัดเจนขึ้น

ตัวอย่าง VLANการใช้งาน
VLAN 10คอมพิวเตอร์สำนักงาน
VLAN 20ระบบ IP Camera
VLAN 30Wi-Fi สำหรับผู้ใช้งาน
VLAN 40Server และระบบส่วนกลาง

การใช้งาน VLAN ต้องตั้งค่าบน Managed Switch และ Router / Layer 3 Gateway ให้สอดคล้องกัน รวมถึงกำหนด Firewall Rule หรือ ACL ให้ NVR และผู้ดูแลเข้าถึงกล้องได้เฉพาะที่จำเป็น ไม่ควรเปิดให้ทุก VLAN ติดต่อกันได้ทั้งหมด

6. เลือก NVR และ Hard Disk ให้เหมาะสม

ก่อนเลือก NVR ควรตรวจสอบจำนวน Channel, Incoming Bandwidth, ความละเอียดที่รองรับ, จำนวนช่อง Hard Disk และความเข้ากันได้กับกล้อง

ตัวอย่างการคำนวณพื้นที่จัดเก็บ: กล้อง 8 ตัว Bitrate ตัวละ 4Mbps บันทึกต่อเนื่อง 24 ชั่วโมง จะใช้ข้อมูลประมาณ 345.6GB ต่อวัน หรือประมาณ 10.37TB สำหรับ 30 วัน (ค่าประมาณแบบหน่วยฐานสิบ) ควรเผื่อพื้นที่และตรวจสอบความจุใช้งานจริงของ Hard Disk ด้วย

7. วางระบบให้ดูภาพผ่านมือถือได้อย่างปลอดภัย

การดูภาพจากภายนอกต้องคำนึงถึง Internet, Gateway, DNS, การกำหนด IP และสิทธิ์ผู้ใช้งาน ควรใช้ Cloud / P2P ของผู้ผลิตหรือ VPN ที่ตั้งค่าอย่างปลอดภัย หลีกเลี่ยงการเปิด Port ของกล้องหรือ NVR สู่อินเทอร์เน็ตโดยตรงโดยไม่จำเป็น

ข้อควรรู้: หากอินเทอร์เน็ตภายนอกขัดข้อง ระบบบันทึกภายใน LAN ยังสามารถทำงานต่อได้ หาก Switch, NVR และระบบไฟฟ้ายังปกติ แต่การดูภาพจากนอกสถานที่จะใช้งานไม่ได้จนกว่าการเชื่อมต่อจะกลับมา

8. ตรวจสอบระบบก่อนส่งมอบงาน

ตรวจสอบสายและ Linkทดสอบสาย LAN, การเข้าหัว, Link Speed และคุณภาพการเชื่อมต่อ
ตรวจสอบไฟ PoEยืนยันกำลังไฟและ PoE Budget เพียงพอสำหรับกล้องทุกตัว
ตรวจสอบภาพและการบันทึกทดสอบ Live View, Playback และการบันทึกต่อเนื่อง
ทดสอบการดูภาพจากภายนอกตรวจสอบแอปมือถือ สิทธิ์ผู้ใช้ และการเชื่อมต่อระยะไกล
จัดทำข้อมูลส่งมอบบันทึก IP Address, VLAN, ผังระบบ และข้อมูลอุปกรณ์สำหรับการดูแลในอนาคต

สรุป: ระบบ IP Camera ที่ดี เริ่มจาก Network ที่ออกแบบถูกต้อง

ระบบกล้อง IP Camera ที่มีประสิทธิภาพต้องอาศัยการออกแบบร่วมกันทั้งสาย LAN, PoE Switch, Bandwidth, VLAN, NVR และระบบจัดเก็บข้อมูล การวางแผนตั้งแต่ต้นช่วยลดปัญหาการเชื่อมต่อ เพิ่มความเสถียร และรองรับการขยายระบบในอนาคต
