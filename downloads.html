SOFTWARE & TOOLS

ดาวน์โหลดโปรแกรม

รวมโปรแกรมสำหรับติดตั้ง ตั้งค่า ตรวจสอบ และดูแลระบบ CCTV กับ Network เลือกดาวน์โหลดจากเว็บไซต์ผู้ผลิตหรือแหล่งทางการเพื่อความปลอดภัย

Hikvision

โปรแกรมสำหรับค้นหาอุปกรณ์ ตั้งค่า และดูภาพกล้องบนคอมพิวเตอร์

SADP Toolค้นหาอุปกรณ์ Hikvision ใน LAN, Activate และตั้งค่า IPดาวน์โหลดจาก Hikvision ↗
iVMS-4200ดูภาพสด Playback และจัดการ DVR/NVR/กล้องดาวน์โหลด Client Software ↗
Hikvision Software Centerรวม Software, Tools และเอกสารของผู้ผลิตเปิด Resource Center ↗

Dahua

เครื่องมือค้นหาและตั้งค่าอุปกรณ์ รวมถึงโปรแกรมดูภาพและ Playback

ConfigToolค้นหาอุปกรณ์, Initialize, เปลี่ยน IP และจัดการอุปกรณ์ดาวน์โหลด / คู่มือ ↗
SmartPSS Liteดูภาพสด Playback และจัดการระบบ Dahua บน PCดาวน์โหลดจาก Dahua Wiki ↗
Smart Playerเล่นไฟล์วิดีโอที่ Export จากเครื่องบันทึกดูโปรแกรมที่มีให้ดาวน์โหลด ↗

Ruijie / Reyee

เอกสาร โปรแกรม และ Firmware สำหรับอุปกรณ์ Network

Ruijie Supportค้นหา Software, Firmware, คู่มือ และข้อมูลผลิตภัณฑ์เปิดเว็บไซต์ Support ↗
Ruijie / Reyee Resourcesค้นหาไฟล์ตามรุ่นอุปกรณ์และประเภทเปิดเว็บไซต์ผู้ผลิต ↗

Network Utilities
